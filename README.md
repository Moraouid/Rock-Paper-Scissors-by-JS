# Rock Paper Scissors by JavaScript

A simple browser-based Rock Paper Scissors game built with **HTML**, **CSS**, and **JavaScript**.

The player competes against the computer, and the first player to reach **5 points** wins the game.

## Features

- Choose rock, paper, or scissors.
- Computer choices are generated randomly.
- Live score tracking for the player and computer.
- Round results are displayed after each selection.
- The game ends when one side reaches 5 points.
- Restart the game with the **Try Again** button.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

No dependencies or build tools are required. You only need a modern web browser.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Moraouid/Rock-Paper-Scissors-by-JS.git
   ```

2. Open the project directory:

   ```bash
   cd Rock-Paper-Scissors-by-JS
   ```

3. Open `index.html` in your browser.

## How to Play

1. Select one of the three choices: rock, paper, or scissors.
2. The computer makes a random choice.
3. The winner of the round is determined by the standard rules:
   - Rock beats scissors.
   - Scissors beats paper.
   - Paper beats rock.
4. The first player to score 5 points wins.
